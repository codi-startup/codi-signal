# Codi Signal delivery checklist

## Product surface
- [ ] Deliver a functional Codi Signal cockpit for designing, simulating and monitoring intelligent automations.
- [ ] Provide a visual workflow canvas with triggers, conditions and actions.
- [ ] Provide an operational signal library with selectable examples for local simulation.
- [ ] Provide a local simulation mode that executes a workflow in the browser and shows processed steps.
- [ ] Provide a configurable rule editor for deciding when an automation acts.
- [ ] Provide metrics for total runs, success rate, average duration and processed signals.
- [ ] Provide event history and detailed execution logs with status, duration and responsible step.
- [ ] Provide overview states for active, paused and test workflows.
- [ ] Use a responsive premium Codi identity based on Obsidian, Carbon and emerald green.
- [ ] Provide empty states, execution feedback and success/error notifications.
- [ ] Include contextual documentation for workflows, signals, rules and simulations.

## Delivery
- [ ] Ship an English README with setup, usage, architecture and validation instructions.
- [ ] Validate the production build and preview runtime.
- [ ] Publish all files to a new public GitHub repository without modifying an existing repository.
